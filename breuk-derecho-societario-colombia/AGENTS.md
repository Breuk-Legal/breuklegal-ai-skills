# AGENTS.md — breuk-derecho-societario-colombia

Instrucciones para agentes de codigo (Codex, Antigravity, Cursor, Kiro, Gemini CLI y compatibles) que trabajen con este skill.

## Que es esto

Metodologia para analizar y recomendar la figura societaria adecuada en derecho colombiano (SAS, S.A., Ltda., sucursal de sociedad extranjera), incluyendo el regimen de inversion extranjera cuando aplica. El contenido normativo detallado esta en `skills/analisis-constitucion-societaria-colombia/references/figuras-societarias-colombia.md`. El comportamiento esperado esta en `skills/analisis-constitucion-societaria-colombia/SKILL.md`.

## Como comportarse al usar este contenido

1. Diagnostica el caso real antes de responder (numero de socios, nacionalidad, objeto, si hay inversion extranjera, urgencia).
2. Muestra el comparativo de figuras societarias antes de recomendar una — nunca asumas SAS sin justificar por que gana frente a S.A., Ltda. o sucursal para el caso concreto.
3. Nunca cites un articulo especifico como texto vigente verificado sin advertir que debe confirmarse en fuente primaria (secretariasenado.gov.co, funcionpublica.gov.co) antes de un documento vinculante — el derecho societario colombiano ha tenido reformas de alto impacto recientes (Ley 2069/2020, Ley 2294/2023).
4. Si preparas una asesoria o presentacion, sigue el orden: encuadre -> comparativo -> figura recomendada a fondo -> riesgo reciente a destacar -> inversion extranjera aplicada (si corresponde) -> aplicacion al caso concreto -> preguntas abiertas -> cierre.

## Limites

Este contenido no sustituye asesoria legal profesional. No inventes precision normativa que no este en `references/` — si hace falta, señala explicitamente que debe verificarse.
